📖 Wikimind Food API - Documentation

L'API Wikimind Food vous donne accès à une base de données complète de plus de 2000 aliments avec leurs informations nutritionnelles, provenants de la base CIQUAL 2025.

Version 1.0.0
Disponible
Dernière mise à jour: 12 juin 2026

🎯 Fonctionnalités

  • Recherche d'aliments par nom ou identifiant CIQUAL
  • Récupération des informations nutritionnelles complètes
  • Filtrage par catégories et sous-catégories
  • Requêtes avancées avec filtres personnalisés
  • Authentification sécurisée via clés API
  • Gestion des clés API avec expiration automatique

📋 Prérequis

Pour utiliser l'API Wikimind Food, vous avez besoin de :

  1. Un compte Wikimind (gratuit)
  2. Une clé API valide (générée depuis votre tableau de bord)

🔐 Authentification

Toutes les requêtes à l'API doivent inclure votre clé API dans les headers HTTP.

Headers requis 
X-API-KEY: wm-fdXXXXXXXX

Obtenir une clé API

  1. Connectez-vous à votre compte Wikimind
  2. Allez dans le tableau de bord
  3. Cliquez sur "Créer une nouvelle clé API"
  4. Donnez un nom à votre clé et sélectionnez une date d'expiration
  5. Passez le test anti-bot
  6. Copiez votre clé API (elle ne sera plus affichée après)

Important: Ne partagez jamais votre clé API. Elle donne un accès complet à votre compte.

Format de la clé API

Les clés API Wikimind Food suivent ce format :

wm-fdXXXXXXXX
  • wm : Préfixe pour Wikimind
  • fd : Suffix pour Food API
  • XXXXXXXX : 8 chiffres aléatoires

💻 Exemples de code

JavaScript (Fetch API)

JavaScript 
const API_KEY = 'wm-fd12345678';
const BASE_URL = 'https://wikimind-food-api.web.app/api';

// Rechercher des aliments
async function searchFood(query) {
  const response = await fetch(`${BASE_URL}/food/search?query=${query}`, {
    headers: {
      'X-API-KEY': API_KEY
    }
  });
  return await response.json();
}

// Obtenir un aliment par ID
async function getFoodById(id) {
  const response = await fetch(`${BASE_URL}/food/${id}`, {
    headers: {
      'X-API-KEY': API_KEY
    }
  });
  return await response.json();
}

// Exemple d'utilisation
searchFood('pomme')
  .then(data => console.log(data))
  .catch(error => console.error(error));

Python (requests)

Python 
import requests

API_KEY = 'wm-fd12345678'
BASE_URL = 'https://wikimind-food-api.web.app/api'

def search_food(query):
    headers = {'X-API-KEY': API_KEY}
    response = requests.get(f'{BASE_URL}/food/search', params={'query': query}, headers=headers)
    return response.json()

def get_food_by_id(food_id):
    headers = {'X-API-KEY': API_KEY}
    response = requests.get(f'{BASE_URL}/food/{food_id}', headers=headers)
    return response.json()

# Exemple d'utilisation
result = search_food('pomme')
print(result)

PHP (cURL)

PHP 
<?php
$apiKey = 'wm-fd12345678';
$baseUrl = 'https://wikimind-food-api.web.app/api';

function searchFood($query) {
    global $apiKey, $baseUrl;

    $url = $baseUrl . '/food/search?query=' . urlencode($query);
    $headers = ['X-API-KEY: ' . $apiKey];

    $ch = curl_init();
    curl_setopt($ch, CURLOPT_URL, $url);
    curl_setopt($ch, CURLOPT_HTTPHEADER, $headers);
    curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);

    $response = curl_exec($ch);
    curl_close($ch);

    return json_decode($response, true);
}

// Exemple d'utilisation
$result = searchFood('pomme');
print_r($result);
?>

Node.js (Axios)

Node.js 
const axios = require('axios');

const API_KEY = 'wm-fd12345678';
const BASE_URL = 'https://wikimind-food-api.web.app/api';

async function searchFood(query) {
  try {
    const response = await axios.get(`${BASE_URL}/food/search`, {
      params: { query },
      headers: { 'X-API-KEY': API_KEY }
    });
    return response.data;
  } catch (error) {
    console.error('Error:', error.response?.data || error.message);
  }
}

// Exemple d'utilisation
searchFood('pomme')
  .then(data => console.log(data))
  .catch(error => console.error(error));

⚖️ Limites et quotas

📊 Limites par clé API

  • Requêtes par minute: 100
  • Requêtes par heure: 1000
  • Requêtes par jour: 10 000

Ces limites sont par clé API. Pour des besoins plus importants, contactez-nous.

⏳ Limites de temps

  • Durée maximale d'une clé: 1 an
  • Durée minimale: 7 jours
  • Renouvellement: Possible à tout moment

🔍 Limites de recherche

  • Résultats par requête: Maximum 50
  • Longueur de la requête: Maximum 100 caractères
  • Profondeur des résultats: Tous les champs disponibles

Gestion des limites

Lorsque vous atteignez une limite, l'API retournera une réponse avec le code d'erreur 429 Too Many Requests.

JSON 
{
  "success": false,
  "error": {
    "code": "RATE_LIMIT_EXCEEDED",
    "message": "Vous avez dépassé la limite de requêtes. Veuillez patienter avant de réessayer.",
    "retryAfter": 60
  },
  "timestamp": "2026-06-12T10:00:00Z"
}

Conseil: Pour éviter les limites, utilisez le cache côté client et regroupez vos requêtes quand c'est possible.

❌ Gestion des erreurs

L'API retourne toujours un objet JSON avec un champ success pour indiquer si la requête a réussi ou non.

Codes d'erreur courants

Code HTTP Code d'erreur Description
400 BAD_REQUEST Requête mal formée ou paramètres manquants
401 UNAUTHORIZED Clé API manquante ou invalide
403 FORBIDDEN Clé API expirée ou désactivée
404 NOT_FOUND Ressource non trouvée
429 RATE_LIMIT_EXCEEDED Limite de requêtes dépassée
500 INTERNAL_ERROR Erreur interne du serveur

Exemple de réponse d'erreur

JSON 
{
  "success": false,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Clé API invalide ou expirée",
    "details": {
      "providedKey": "wm-fdXXXXXXXX",
      "expectedFormat": "wm-fd[8 chiffres]"
    }
  },
  "timestamp": "2026-06-12T10:00:00Z"
}
