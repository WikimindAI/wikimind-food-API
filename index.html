Introduction

                
L'API Wikimind Food vous donne accès à une base de données complète d'aliments basée sur CIQUAL 2025. Chaque aliment contient des informations nutritionnelles détaillées, des catégories et des métadonnées.

                
                
Fonctionnalités

                
    
                  
  • Accès à plus de 2000 aliments
    • 
                  
  • Recherche par nom, catégorie ou ID
    • 
                  
  • Filtrage avancé
    • 
                  
  • Données nutritionnelles complètes
    • 
                


                
Base URL

                
https://wikimind-food-api.web.app/api

              


              

                
Authentification

                
Toutes les requêtes à l'API doivent inclure une clé API valide dans les headers.


                
Obtenir une clé API

                
    
                  
  1. Connectez-vous à votre compte Wikimind
    2. 
                  
  2. Allez dans la section "Créer une clé API"
    3. 
                  
  3. Remplissez le formulaire et passez le test anti-bot
    4. 
                  
  4. Copiez votre nouvelle clé API
    5. 
                


                
Utilisation de la clé API

                
Ajoutez la clé API dans les headers de vos requêtes :

                
X-API-Key: wm-fd12345678

                
Ou en paramètre de requête :

                
?api_key=wm-fd12345678

Exemples de code


                

                  
cURL

                  
# Récupérer un aliment spécifique
curl -X GET "https://wikimind-food-api.web.app/api/food/24999" \
  -H "X-API-Key: wm-fd12345678"

# Rechercher des aliments
curl -X GET "https://wikimind-food-api.web.app/api/food/search?q=pomme" \
  -H "X-API-Key: wm-fd12345678"

# Filtrer par catégorie
curl -X GET "https://wikimind-food-api.web.app/api/food/category?group=1&subgroup=101" \
  -H "X-API-Key: wm-fd12345678"

                


                

                  
JavaScript (Fetch API)

                  
const API_KEY = 'wm-fd12345678';
const BASE_URL = 'https://wikimind-food-api.web.app/api';

// Récupérer un aliment
async function getFoodItem(id) {
  const response = await fetch(`${BASE_URL}/food/${id}`, {
    headers: {
      'X-API-Key': API_KEY
    }
  });
  return await response.json();
}

// Rechercher des aliments
async function searchFood(query) {
  const response = await fetch(`${BASE_URL}/food/search?q=${encodeURIComponent(query)}`, {
    headers: {
      'X-API-Key': API_KEY
    }
  });
  return await response.json();
}

// Utilisation
getFoodItem('24999').then(data => console.log(data));
searchFood('pomme').then(results => console.log(results));

                


                

                  
Python (requests)

                  
import requests

API_KEY = 'wm-fd12345678'
BASE_URL = 'https://wikimind-food-api.web.app/api'

# Récupérer un aliment
response = requests.get(
    f'{BASE_URL}/food/24999',
    headers={'X-API-Key': API_KEY}
)
data = response.json()
print(data)

# Rechercher des aliments
response = requests.get(
    f'{BASE_URL}/food/search',
    params={'q': 'pomme'},
    headers={'X-API-Key': API_KEY}
)
results = response.json()
print(results)

                

              


              

                
Limites et quotas

                
L'API Wikimind Food applique les limites suivantes pour garantir un service de qualité à tous les utilisateurs.


                
Limites par clé API

                

                  
                    
Type de requêteLimitePériode

                  
                  
                    
Requêtes depuis GitHub PagesIllimité-

                    
Requêtes externes1000par jour

                    
Requêtes par minute60par minute

                  
                


                
Headers de limite

                
Chaque réponse inclut les headers suivants pour vous aider à suivre votre utilisation :

                
X-RateLimit-Limit: 1000
X-RateLimit-Remaining: 999
X-RateLimit-Reset: 86400

              


              

                
Codes d'erreur

                
L'API retourne les codes d'erreur HTTP standard. Voici les erreurs spécifiques que vous pouvez rencontrer :


                

                  
                    
CodeMessageDescriptionSolution

                  
                  
                    

                      401
                      API key required
                      La clé API est manquante dans la requête
                      Ajoutez la clé API dans les headers ou paramètres
                    

                    

                      403
                      Invalid API key
                      La clé API fournie n'est pas valide
                      Vérifiez votre clé API et créez-en une nouvelle si nécessaire
                    

                    

                      403
                      API key expired
                      La clé API a expiré
                      Créez une nouvelle clé API
                    

                    

                      403
                      API key deactivated
                      La clé API a été révoquée
                      Créez une nouvelle clé API
                    

                    

                      404
                      Food item not found
                      L'aliment demandé n'existe pas
                      Vérifiez l'ID de l'aliment
                    

                    

                      429
                      Daily limit exceeded
                      La limite quotidienne a été dépassée
                      Attendez le lendemain ou créez une nouvelle clé
                    

                    

                      429
                      Rate limit exceeded
                      Trop de requêtes par minute
                      Attendez quelques secondes avant de réessayer
